# SOA · 性取向光谱分析（Sexual Orientation Spectrum）

> **完全原创** · 开源免费 · Apache 2.0 · 版权归作者
> 作者：**Maxx-EX** · 联系：programmingscience@foxmail.com

一套完全原创的**性取向自我分析系统**——不抄袭任何既有量表，把取向当作**多元、流动的光谱**而非单一线条，帮助你在吸引、认同、情感联结、流动探索、自我接纳与环境支持六个切面上，更清楚地看见真实的自己。

## ✨ 特点

- **60 道原创题**，每题 4 选项；**6 大原创维度**，每维 10 题，含反向题与维度交错出题。
- **多元光谱而非单轴**：不同于传统单线刻度，从多切面刻画你的取向。
- **双指标分析**：PBI（维度均值）+ SC（维度标准差），水平与均衡度并看。
- **取向倾向软性描述**：只反映你此刻自我报告中的倾向，不定义、不贴标签。
- **诚实定位**：自我探索工具，非诊断、非医学鉴定（详见 `docs/validation.md`）。

## 🧭 六大维度

| 维度 | key | 说明 |
|---|---|---|
| 吸引取向 | atr | 情感与身体层面被怎样的人吸引（同性 / 异性 / 双性 / 流动） |
| 认同舒适 | ide | 对自身取向的清晰度与自在程度 |
| 情感联结 | aff | 超越身体的浪漫与情感亲近 |
| 流动探索 | flx | 对取向流动的开放与探索的从容 |
| 自我接纳 | acc | 不含羞耻、不自我否定的内在善待 |
| 环境支持 | ctx | 身边环境与你可获得的接纳与安全感 |

## 🧪 测量学定位（诚实声明）

SOA 是**开源自我探索工具**，而非经过实证校准的标准化量表：已验证内容原创、维度—题目映射与计分自洽；但**尚无**常模、重测信度、内部一致性（α）、效标效度与因子分析，各维度分带阈值为暂定值。详见 [docs/validation.md](docs/validation.md)。
