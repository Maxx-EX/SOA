# SOA · 性取向光谱分析（Sexual Orientation Spectrum）

完全原创的性取向自我探索分析系统。作者 **Maxx-EX** · 开源免费（Apache 2.0）· 版权归作者。

- 量表：**60 道原创题**，每题 4 选项（非常不符合 / 较不符合 / 较符合 / 非常符合）。
- 维度：**6 个原创构念**，每维 10 题，含反向题与维度交错出题。
- 分析：维度标准化 0–100、PBI（均值）+ SC（标准差）双指标、取向倾向、综合画像。
- 定位：**自我探索工具，非诊断、非医学鉴定**。

---

## 一、为什么是"光谱"，而不是一条单一线

传统上常用单一刻度（如从一端到另一端的直线）描述性取向。SOA 有意不用这种单轴模型，而是把取向拆成**多个可流动的切面**，让每个人根据自己的真实感受在不同维度上"各就各位"。这一设计是原创的，不与任何既有量表雷同。

## 二、六大原创维度

| 维度 | key | 说明 |
|---|---|---|
| 吸引取向 | atr | 你在情感与身体层面被怎样的人吸引——分同性 / 异性 / 双性与流动三组题观察。 |
| 认同舒适 | ide | 你对自身取向的清晰度与自在程度。 |
| 情感联结 | aff | 超越身体的浪漫与情感亲近，强调"灵魂层面的靠近"。 |
| 流动探索 | flx | 对取向随经历流动的开放，以及探索时的从容。 |
| 自我接纳 | acc | 不含羞耻、不自我否定的内在善待。 |
| 环境支持 | ctx | 身边环境与你可获得的接纳、安全感（作为支持资源观测，非取向本身）。 |

## 三、计分口径

- 每维 10 题，选项 1–4 分；反向题按 `5 − 原始分` 反转。
- 维度原始均分 1–4 → 标准化 `(均值 − 1) / 3 × 100`，保留 0.1。
- PBI = 已答维度均值；SC = 维度间标准差。
- 分带：≥66 高亮 / 40–65 中亮 / <40 低亮（仅描述相对位置，无好坏）。

## 四、取向倾向（仅描述，不定义）

系统会结合吸引取向维度的同性 / 异性 / 双性 / 流动子题，输出一条"**当下倾向**"的软性描述（如"更偏同性别吸引""双性吸引倾向""吸引方向偏流动"等）。它**只反映你此刻自我报告中的倾向**，不替你贴标签，也不宣称永恒——是否认同某个词、如何认同，完全由你决定。

## 五、自我探索立场

- 性取向**不是疾病**，也不是个人选择；它是多元、流动且私密的个人维度。
- 本项目**不包含**任何"改变取向"的导向（这类做法有害且无必要）。
- 若你因取向、认同或相关压力感到持续困扰，请寻求专业心理咨询支持。

## 六、数据与隐私

默认**不收集、不上传任何作答数据**，全程在作答者浏览器本地运行。
